# موشن گرافیک تبلیغاتی رسا استودیو

یک موشن گرافیک ۳۲ ثانیه‌ای (1920×1080) با تم لاجوردی و طلایی برای معرفی سه سایت:
`rasa-to.ir` · `rasa-home.ir` · `rasa-promt.ir`

## سکانس‌ها
| زمان | صحنه |
|---|---|
| 0 تا 5 ثانیه | اینترو: ستاره‌ی هشت‌پر (گره) خودش را می‌کشد، لوگو و نام «رسا استودیو» ظاهر می‌شوند |
| 5 تا 11.5 ثانیه | رسا تو: مرورگر با تایپ آدرس، آیکون مکان با موج |
| 11.5 تا 18 ثانیه | رسا هوم: خانه‌ای که خط‌به‌خط کشیده می‌شود |
| 18 تا 24.5 ثانیه | رسا پرامپت: پرامپت در حال تایپ و درخشش‌ها |
| 24.5 تا 32 ثانیه | جمع‌بندی: هر سه لوگو، شعار و دکمه‌ی دعوت به اقدام (لوپ بی‌وقفه) |

## پیش‌نمایش
فایل `motion/index.html` را در مرورگر باز کنید. (Space = توقف/پخش، نوار پایین برای جابه‌جایی در زمان)

## ویرایش
- **متن‌ها، رنگ هر سایت و مسیر لوگوها:** شیء `CONFIG` در بالای اسکریپت `motion/index.html`
- **لوگوها:** در `motion/logos/` (راهنما در همان پوشه)
- **رنگ‌های اصلی:** متغیرهای `:root` در CSS

## خروجی ویدیو (MP4)
```bash
cd motion
npm i playwright && npx playwright install chromium   # یک بار
node export.mjs rasa-studio-promo.mp4 30
```
نیاز به `ffmpeg` در PATH دارد. خروجی نمونه: `motion/rasa-studio-promo.mp4`

# ۰۶ — سئو و برنامه‌ی رشد

## ۱. معماری URL

| صفحه | الگو | مثال |
|---|---|---|
| خانه | `/{locale}` | `/fa` |
| پرامپت | `/{locale}/p/{slug}` | `/fa/p/کپشن-اینستاگرام-فروشگاه-لباس` |
| دسته | `/{locale}/c/{category}` | `/ar/c/التسويق` |
| مدل | `/{locale}/m/{model}` | `/en/m/midjourney` |
| ترکیب مدل × کاربرد | `/{locale}/m/{model}/{category}` | `/en/m/claude/coding` |
| برچسب | `/{locale}/t/{tag}` | |
| باندل | `/{locale}/b/{slug}` | |
| آکادمی/وبلاگ | `/{locale}/learn/{slug}` | |
| مقایسه | `/{locale}/vs/{competitor}` | `/fa/vs/promptbase` |
| ابزار رایگان | `/{locale}/tools/{tool}` | `/fa/tools/prompt-generator` |

- slug در هر زبان به خط همان زبان (فارسی/عربی) — Google به‌خوبی پشتیبانی می‌کند.
- `hreflang` برای fa، ar، en و `x-default` → en.
- canonical روی هر نسخه‌ی زبانی خودش.

## ۲. سئوی برنامه‌ای (Programmatic SEO)
- **یک صفحه برای هر پرامپت** (هزاران صفحه‌ی long-tail) — الگوی PromptHero.
- **صفحات ترکیبی** «مدل × کاربرد» و «کاربرد × صنعت» فقط وقتی ≥ ۸ پرامپت دارند (جلوگیری از thin content).
- محتوای منحصربه‌فرد در هر صفحه: نمونه‌خروجی واقعی، امتیاز تست، راهنمای استفاده، FAQ تولیدشده از سؤالات واقعی کاربران.
- Schema.org: `Product` + `Offer` + `AggregateRating` (فقط با نظر واقعی)، `HowTo`، `FAQPage`، `BreadcrumbList`.

## ۳. ابزارهای رایگان جذب ترافیک (Lead Magnet)
| ابزار | بازار | کار |
|---|---|---|
| پرامپت‌ساز (Prompt Generator) | هر سه | ایده‌ی ساده → پرامپت حرفه‌ای (۳ بار رایگان، بعد ثبت‌نام) |
| بهبوددهنده‌ی پرامپت | هر سه | پرامپت کاربر را امتیاز و بازنویسی می‌کند |
| مترجم پرامپت فارسی/عربی → انگلیسی برای Midjourney | fa، ar | پرجست‌وجو و کم‌رقیب |
| چک‌لیست/چیت‌شیت PDF | هر سه | در ازای ایمیل/شماره |

## ۴. کانال‌ها به تفکیک بازار

### فارسی
1. **سئو** (کانال اصلی) — رقبای ایرانی صفحه‌ی پرامپت تکی ایندکس‌شده و نمونه‌خروجی ندارند.
2. **اینستاگرام**: ریلز «قبل/بعد پرامپت» ۳ بار در هفته (خودکار P6) + همکاری با پیج‌های آموزش AI (افیلیت ۳۰٪).
3. **تلگرام**: کانال «پرامپت روز» + ربات جست‌وجو/خرید.
4. **آپارات / یوتیوب**: ویدیوهای کوتاه آموزشی از قالب ثابت.
5. **مقاله‌های مقایسه‌ای** با رقبای ایرانی و خارجی (صادقانه و قابل‌دفاع).

### عربی
1. **سئو عربی** — رقابت بسیار کم (سند بنچمارک).
2. **X (توییتر)**: بسیار پرکاربرد در عربستان و خلیج؛ رشته‌توییت روزانه.
3. **تیک‌تاک و اسنپ‌چت** (عربستان): ویدیوی کوتاه قبل/بعد.
4. **یوتیوب عربی**: آموزش ابزارها.
5. حضور در **خمسات / Gumroad** با یک پک کوچک به‌عنوان قیف ورودی به سایت.

### انگلیسی
1. **سئو برنامه‌ای** + مقالات «best prompts for X».
2. **Chrome Web Store** (افزونه = کانال توزیع رایگان، الگوی AIPRM).
3. **Product Hunt** (لانچ هفته‌ی ۱۴)، **Reddit** (مشارکت واقعی در r/ChatGPT، r/PromptEngineering، r/midjourney)، **X**.
4. **Pinterest** برای پرامپت‌های تصویری.
5. **خبرنامه** و تبادل خبرنامه با نویسندگان حوزه‌ی AI.
6. فهرست شدن در دایرکتوری‌های ابزار AI.

## ۵. تقویم محتوای خودکار (هفتگی)
| روز | fa | ar | en |
|---|---|---|---|
| هر روز | پرامپت روز (تلگرام، استوری) | پرامپت روز (X) | پرامپت روز (X) |
| ۳ بار در هفته | ریلز قبل/بعد | ویدیو کوتاه | پین Pinterest |
| هفتگی | ۲ مقاله‌ی آکادمی | ۲ مقاله | ۲ مقاله |
| هفتگی | خبرنامه | خبرنامه | خبرنامه |
| ماهانه | باندل جدید + کمپین | باندل جدید | باندل جدید |
| مناسبتی | نوروز، یلدا، بلک‌فرایدی ایرانی | رمضان، عید، روز ملی عربستان/امارات | Black Friday، New Year |

همه از پایگاه‌داده تولید می‌شوند؛ نقش شما فقط تأیید **باندل ماهانه** و **کمپین مناسبتی** است.

## ۶. حلقه‌های رشد (Growth Loops)
1. **حلقه‌ی سئو:** جست‌وجوی بی‌نتیجه → DemandSignal → پرامپت جدید → صفحه‌ی جدید → ترافیک بیشتر.
2. **حلقه‌ی اشتراک‌گذاری:** هر نمونه‌خروجی/اجرای کاربر یک لینک قابل اشتراک با واترمارک برند دارد.
3. **حلقه‌ی به‌روزرسانی:** مدل جدید → ایمیل «پرامپت‌های شما به‌روز شد» → بازگشت → فروش متقاطع.
4. **حلقه‌ی افیلیت:** مدرس‌ها محتوا می‌سازند → ۳۰٪ می‌گیرند → محتوای بیشتر.
